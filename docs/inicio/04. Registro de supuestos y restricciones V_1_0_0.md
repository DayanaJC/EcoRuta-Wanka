## 2. Introducción

El presente documento registra los principales **supuestos y restricciones** considerados durante la planificación y desarrollo del proyecto **EcoRuta Wanka**, una aplicación web orientada a la gestión de vehículos, pedidos, asignaciones y optimización de rutas de reparto.

La identificación de estos elementos permite reconocer las condiciones que se consideran verdaderas para la ejecución del proyecto y los factores que limitan las decisiones relacionadas con el alcance, tiempo, tecnología, costos y operación del sistema.

Este registro será actualizado durante las diferentes iteraciones del proyecto cuando aparezcan nuevos supuestos, restricciones o cambios en las condiciones iniciales.

# 3. Registro de Supuestos

Los supuestos representan condiciones que se consideran verdaderas para poder planificar y desarrollar el proyecto, aunque deben ser verificadas durante su ejecución.

| ID    | Descripción                                                                                                                                                                   | Categoría  | Grado de Impacto | Estrategia de Validación                                                                                      |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ---------------- | ------------------------------------------------------------------------------------------------------------- |
| AS-01 | Se asume que el equipo de desarrollo dispondrá de computadoras adecuadas para ejecutar el backend, frontend y herramientas de desarrollo.                                     | Técnica    | Alto             | Verificar la disponibilidad y capacidad de los equipos durante cada iteración.                                |
| AS-02 | Se asume que el servicio Firebase/Firestore estará disponible para almacenar y consultar la información del sistema.                                                          | Técnica    | Alto             | Realizar pruebas de conexión y disponibilidad mediante el backend.                                            |
| AS-03 | Se asume que los usuarios dispondrán de conexión a Internet para utilizar la aplicación web y acceder a los servicios en la nube.                                             | Operativa  | Medio            | Verificar conectividad durante las pruebas de funcionamiento.                                                 |
| AS-04 | Se asume que los pedidos registrados contienen información suficiente para su gestión y posterior planificación de rutas.                                                     | Operativa  | Alto             | Validar los campos obligatorios durante el registro de pedidos.                                               |

| AS-12 | Se asume que los indicadores de distancia, combustible y emisiones calculados por el sistema podrán utilizarse como estimaciones para evaluar la sostenibilidad de las rutas. | Operativa  | Medio            | Comparar los cálculos con escenarios de prueba y verificar las fórmulas implementadas.                        |

# 4. Registro de Restricciones

Las restricciones representan condiciones que limitan las alternativas disponibles para el desarrollo y operación del proyecto.

| ID    | Descripción                                                                                                                                                   | Categoría  | Severidad | Flexibilidad de Negociación |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------- | --------------------------- |

| CO-02 | El sistema debe desarrollarse como un Producto Mínimo Viable (PMV), por lo que el alcance está limitado a las funcionalidades priorizadas.                    | Tiempo     | Alta      | Media                       |
| CO-03 | El desarrollo debe utilizar una separación clara entre frontend y backend.                                                                                    | Tecnología | Alta      | Baja                        |

| CO-05 | El frontend utiliza React y Vite para la implementación de la interfaz web.                                                                                   | Tecnología | Media     | Media                       |
| CO-06 | El sistema depende de servicios externos de infraestructura en la nube, principalmente Firebase/Firestore.                                                    | Tecnología | Alta      | Media                       |

# 5. Consideraciones de gestión

Los supuestos y restricciones serán revisados periódicamente durante las iteraciones del proyecto. Si un supuesto deja de cumplirse, deberá convertirse en un riesgo o generar una actualización de los requisitos, planificación o diseño del sistema.

Asimismo, cualquier modificación significativa de una restricción deberá ser evaluada por el equipo para determinar su impacto sobre el alcance, tiempo, costo, calidad y sostenibilidad del proyecto.

La gestión de estos elementos permitirá mantener una visión realista del desarrollo de **EcoRuta Wanka** y facilitar la toma de decisiones frente a cambios o incertidumbres durante las siguientes iteraciones.
