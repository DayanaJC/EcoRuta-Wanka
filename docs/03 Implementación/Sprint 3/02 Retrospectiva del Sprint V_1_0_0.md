## ¿Qué aprendimos?

- Aprendimos que, antes de modificar una ruta, es importante verificar si el cambio mejora realmente la organización de las entregas.
- Aprendimos que las historias grandes deben dividirse en tareas pequeñas para facilitar su desarrollo y revisión.
- Aprendimos que las pruebas automáticas permiten comprobar que las nuevas funcionalidades no afecten el funcionamiento de las anteriores.
- Aprendimos que mantener actualizados el repositorio, el README y Jira facilita el seguimiento de los avances del proyecto.

## ¿Qué estamos haciendo bien?

- Se mantuvo una buena comunicación entre los dos integrantes durante el desarrollo del Sprint.
- Se completaron las **2 historias de usuario planificadas**, alcanzando los **18 de 18 puntos**.
- Se finalizaron las **9 de 9 historias de usuario** previstas para el proyecto.
- Se implementaron pruebas automáticas para verificar los criterios de aceptación, alcanzando un total de **109 pruebas**.
- Se realizaron verificaciones de calidad mediante SonarQube para identificar posibles errores y mejorar el funcionamiento del sistema.
- Se completó la integración entre la interfaz y el servidor, verificando el correcto intercambio de datos.
- Se subieron los cambios y las evidencias correspondientes al repositorio durante el Sprint.
