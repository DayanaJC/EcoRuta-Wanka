### US-004 – Visualización de rutas en el mapa

Se implementó la visualización de las rutas generadas en el mapa. El sistema permite observar la ruta y los puntos correspondientes a las entregas.

| Escenario                        | Resultado  | Evidencia                                                               |
| -------------------------------- | ---------- | ----------------------------------------------------------------------- |
| Visualizar una ruta generada     | **Cumple** | La ruta generada se muestra en el mapa junto con sus puntos de entrega. |
| Visualizar los puntos de entrega | **Cumple** | Los puntos correspondientes a las entregas se muestran en el mapa.      |
| Consultar la ruta generada       | **Cumple** | Se puede visualizar la información de la ruta desde el sistema.         |

**Evidencia principal:**

### US-005 – Dashboard de sostenibilidad

| Escenario                                              | Resultado  | Evidencia                                                                              |
| ------------------------------------------------------ | ---------- | -------------------------------------------------------------------------------------- |
| Consultar los indicadores de sostenibilidad            | **Cumple** | El sistema muestra los indicadores disponibles.                                        |
| Visualizar el indicador de entregas dentro del horario | **Cumple** | Se muestra el indicador correspondiente a las entregas dentro del horario establecido. |
