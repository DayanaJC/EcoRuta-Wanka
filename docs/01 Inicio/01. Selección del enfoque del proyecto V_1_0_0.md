# EcoRuta Wanka

*Optimizador de rutas sostenibles de última milla — Huancayo, Junín*

# 01. Selección del enfoque del proyecto

**Versión:** V_1_0_0 | **Fecha:** 28/08/2026 | **Organización:** WankaLogística S.A.C. | **Ubicación:** Huancayo, Junín, Perú

**Integrantes:** Arroyo Canchari Henry, Javier Curi Dayana

---

## 1. Introducción

EcoRuta Wanka es un proyecto orientado al desarrollo de una plataforma web para apoyar la gestión de pedidos, vehículos y rutas de reparto de última milla en Huancayo, El Tambo, Chilca y Pilcomayo.

Para organizar el desarrollo del proyecto se evaluaron tres enfoques: **predictivo, ágil e híbrido**. Después de analizar las características del proyecto, se seleccionó el **enfoque híbrido**, debido a que algunas actividades requieren una planificación previa, mientras que otras pueden desarrollarse y mejorarse de manera progresiva.

---

## 2. Matriz de evaluación de variables

Para seleccionar el enfoque se consideraron cinco aspectos importantes del proyecto. Se utilizó una escala del 1 al 5:

* **1:** mayor relación con un enfoque predictivo.
* **5:** mayor relación con un enfoque ágil.

| N° | Variable de evaluación              | Puntaje | Justificación                                                                           | Favorece    |
| -- | ----------------------------------- | ------: | --------------------------------------------------------------------------------------- | ----------- |
| 1  | Claridad de los requisitos          |       2 | Una parte importante de los requisitos del proyecto puede definirse desde el inicio.    | Predictivo  |
| 2  | Cambios durante el desarrollo       |       4 | Algunas características pueden necesitar ajustes a medida que se avance en el proyecto. | Ágil        |
| 3  | Participación de los usuarios       |       4 | Es importante recibir opiniones y realizar mejoras durante el desarrollo.               | Ágil        |
| 4  | Cumplimiento de requisitos y normas |       1 | Los requisitos establecidos y las normas deben considerarse desde el inicio.            | Predictivo  |
| 5  | Desarrollo por etapas               |       4 | El proyecto puede desarrollarse por partes, permitiendo revisar y mejorar cada avance.  | Ágil        |
|    | **Puntaje promedio**                | **3.0** | El resultado se encuentra en un punto intermedio entre los dos enfoques.                | **Híbrido** |

---

## 3. Representación del perfil del proyecto

Los resultados muestran que EcoRuta Wanka presenta características tanto del enfoque predictivo como del enfoque ágil.

Algunos aspectos, como la definición de requisitos y el cumplimiento de normas, requieren planificación desde el inicio. En cambio, el desarrollo de las funcionalidades y las mejoras del sistema pueden realizarse progresivamente.

Por esta razón, el proyecto presenta un perfil **híbrido**.

---

## 4. Enfoque seleccionado

### Enfoque de desarrollo elegido: HÍBRIDO

EcoRuta Wanka utilizará un **enfoque híbrido**, combinando planificación previa con un desarrollo progresivo.

En la primera etapa se establecerán los principales requisitos, objetivos, organización del proyecto y estructura del sistema.

Posteriormente, el desarrollo se realizará por etapas. En cada etapa se podrán revisar los avances, realizar pruebas y efectuar las mejoras necesarias.

De esta manera, el proyecto mantiene una planificación general, pero también permite realizar cambios cuando sean necesarios durante el desarrollo.

---

## 5. Justificación

Se seleccionó el enfoque híbrido por las siguientes razones:

* Permite definir desde el inicio los principales objetivos y requisitos del proyecto.
* Permite organizar las actividades y establecer un orden de trabajo.
* Facilita desarrollar el sistema por partes.
* Permite revisar los avances durante el desarrollo.
* Permite realizar mejoras cuando se encuentren necesidades o cambios.
* Facilita recibir opiniones sobre el funcionamiento del sistema.
* Permite mantener una organización clara del proyecto sin impedir que se realicen mejoras.

Por estas razones, el **enfoque híbrido** se considera adecuado para organizar el desarrollo de EcoRuta Wanka.
