## 1. Propósito y justificación del proyecto

Las empresas dedicadas al reparto de productos en Huancayo y zonas cercanas pueden enfrentar dificultades para organizar sus pedidos, vehículos y rutas de entrega. Entre estas dificultades se encuentran el tráfico, los tiempos de desplazamiento, las condiciones de las vías, el clima y la necesidad de cumplir con los horarios establecidos para las entregas.

Estas situaciones pueden generar recorridos innecesarios, mayores gastos asociados al reparto y retrasos en las entregas.

**EcoRuta Wanka** es un proyecto académico que propone desarrollar una plataforma web para apoyar la organización de los pedidos, vehículos y rutas de reparto de una empresa de distribución ficticia denominada **WankaLogística S.A.C.**

El sistema busca facilitar la planificación de las rutas de entrega, mejorar la organización de las operaciones y proporcionar información relacionada con los recorridos, horarios y sostenibilidad.

Los datos utilizados durante el desarrollo serán simulados y estarán relacionados con las características del reparto en Huancayo y zonas cercanas.

## 2. Objetivos SMART

| ID     | Objetivo                                                             | Meta                                                                                                                           |
| ------ | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **O1** | Reducir el impacto ambiental generado por los recorridos de reparto. | Reducir en **20%** las emisiones estimadas de CO₂ durante los primeros 6 meses de uso del sistema.                             |
| **O2** | Mejorar el cumplimiento de los horarios de entrega.                  | Reducir a menos del **10%** las entregas realizadas fuera del horario establecido durante los primeros 4 meses.                |
| **O3** | Reducir los gastos asociados a los recorridos de reparto.            | Lograr un ahorro estimado del **15%** en combustible y mantenimiento durante el primer año.                                    |
| **O4** | Desarrollar el alcance funcional definido para el MVP.               | Completar el alcance funcional establecido para el MVP durante el periodo académico del proyecto.                              |
| **O5** | Garantizar una experiencia de uso adecuada.                          | Lograr que al menos el **90% de los usuarios de prueba** califiquen el sistema con una puntuación de **4 sobre 5 o superior**. |

## 3. Alcance inicial del proyecto

EcoRuta Wanka contempla el desarrollo de una plataforma web orientada a apoyar las operaciones de reparto.

El alcance inicial comprende:

* Gestión de vehículos.
* Gestión de pedidos de reparto.
* Generación de rutas optimizadas.
* Visualización y seguimiento de rutas.
* Indicadores de sostenibilidad.
* Reportes de sostenibilidad.
* Re-optimización de rutas.
* Gestión de conductores y asignación de rutas.
* Gestión de preferencias de clientes y bodegas.
* Autenticación y control de acceso por roles.
