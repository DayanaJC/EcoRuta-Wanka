## 1. Problema y justificación

Las empresas dedicadas al reparto de productos en Huancayo y zonas cercanas pueden enfrentar dificultades para organizar sus pedidos, vehículos y rutas de entrega. Entre estas dificultades se encuentran el tráfico en determinadas zonas, los tiempos de desplazamiento, las condiciones de las vías, el clima y la necesidad de cumplir con los horarios establecidos para las entregas.

Estas situaciones pueden ocasionar recorridos innecesarios, mayor consumo de combustible y retrasos en la entrega de los pedidos.

**EcoRuta Wanka** es un proyecto académico que propone desarrollar una plataforma web para apoyar la organización de los pedidos, vehículos y rutas de reparto de una empresa de distribución ficticia denominada **WankaLogística S.A.C.**

El sistema busca facilitar la planificación de las rutas de entrega, reducir recorridos innecesarios y apoyar una mejor organización de las operaciones de reparto.

Los datos utilizados para el proyecto serán simulados y estarán relacionados con las características del reparto en Huancayo y sus alrededores.

## 2. Objetivos SMART

| N°     | Objetivo                                                             | Meta                                                                                                                           |
| ------ | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **O1** | Reducir el impacto ambiental generado por los recorridos de reparto. | Reducir en **20%** las emisiones estimadas de CO₂ durante los primeros 6 meses de uso del sistema.                             |
| **O2** | Mejorar el cumplimiento de los horarios de entrega.                  | Reducir a menos del **10%** las entregas realizadas fuera del horario establecido durante los primeros 4 meses.                |
| **O3** | Reducir los gastos relacionados con los recorridos de reparto.       | Lograr un ahorro estimado del **15%** en combustible y mantenimiento durante el primer año.                                    |
| **O4** | Desarrollar una primera versión funcional del sistema.               | Completar al menos el **70% de los requisitos principales** en un plazo de **14 semanas**.                                     |
| **O5** | Facilitar el uso del sistema por parte de los usuarios.              | Lograr que al menos el **90% de los usuarios de prueba** califiquen el sistema con una puntuación de **4 sobre 5 o superior**. |

## 3. Requisitos principales

EcoRuta Wanka deberá considerar las siguientes funciones principales:

* Registrar y administrar los vehículos utilizados para el reparto.
* Registrar y administrar los pedidos de los clientes.
* Organizar los pedidos según los vehículos disponibles.
* Generar rutas de reparto buscando reducir recorridos innecesarios.
* Considerar la capacidad de los vehículos al organizar las entregas.
* Considerar los horarios establecidos para las entregas.
* Mostrar información relacionada con las rutas de reparto.
* Presentar información que permita conocer el funcionamiento de las operaciones.
* Generar información que permita evaluar el ahorro de recorridos y el impacto ambiental.
* Proteger la información registrada en el sistema.
* Mantener un tiempo de respuesta adecuado para las operaciones principales.

El detalle de los requisitos se desarrolla en los documentos correspondientes del proyecto.

## 4. Riesgos iniciales

| ID       | Riesgo                                                                                    | Probabilidad | Impacto | Respuesta                                                                                        |
| -------- | ----------------------------------------------------------------------------------------- | ------------ | ------- | ------------------------------------------------------------------------------------------------ |
| **R-01** | La información disponible sobre las rutas y condiciones de las calles puede ser limitada. | Alta         | Medio   | Utilizar información disponible y datos simulados para las pruebas.                              |
| **R-02** | Puede existir una conexión a Internet limitada en algunas zonas.                          | Media        | Alto    | Considerar alternativas para continuar trabajando cuando exista una interrupción temporal.       |
| **R-03** | Algunos usuarios pueden tener dificultades para utilizar el sistema.                      | Media        | Medio   | Diseñar una interfaz sencilla y realizar pruebas con usuarios.                                   |
| **R-04** | Pueden presentarse cambios en los requisitos durante el desarrollo.                       | Baja         | Alto    | Revisar y organizar los cambios antes de incorporarlos al proyecto.                              |
| **R-05** | El cálculo de las rutas puede requerir más tiempo cuando aumente la cantidad de pedidos.  | Media        | Alto    | Realizar pruebas con diferentes cantidades de pedidos y mejorar el cálculo cuando sea necesario. |
| **R-06** | Las condiciones climáticas pueden afectar los tiempos de reparto.                         | Alta         | Medio   | Considerar estas condiciones dentro de la planificación de las rutas.                            |
| **R-07** | No se cuenta con una empresa real que proporcione información operativa.                  | Alta         | Medio   | Trabajar con datos simulados relacionados con las características del reparto en Huancayo.       |
