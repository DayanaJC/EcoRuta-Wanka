## 1. Objeto del documento

Este documento identifica las principales restricciones que pueden afectar el desarrollo y funcionamiento de **EcoRuta Wanka**.

Las restricciones se organizan considerando aspectos de **tiempo, costo, tecnología, datos, alcance, operación, seguridad y sostenibilidad**.

Estas condiciones deben ser consideradas durante la planificación, desarrollo, pruebas y evolución del proyecto.

## 3. Restricciones principales

Las restricciones que tienen mayor relación con el desarrollo de EcoRuta Wanka son las siguientes:

### 3.1 Tiempo académico

El proyecto debe desarrollarse dentro del periodo establecido para el PFA. Por ello, las funcionalidades deben priorizarse para cumplir con los objetivos y entregas establecidos.

### 3.2 Presupuesto

El proyecto se desarrolla con un presupuesto académico limitado. Por esta razón, se priorizan herramientas y servicios que puedan utilizarse con costos reducidos.

### 3.3 Equipo de desarrollo

El equipo está conformado por dos integrantes. Esto requiere distribuir adecuadamente las actividades y controlar el alcance del proyecto.

### 3.4 Dependencia tecnológica

El sistema utiliza servicios como Firebase Cloud Firestore para almacenar información. Por ello, parte de las operaciones depende de la disponibilidad de estos servicios y de una conexión a Internet.

### 3.5 Calidad de los datos

La generación de rutas depende de que los pedidos, vehículos y demás información registrada sean válidos y estén completos.

### 3.6 Alcance geográfico

El proyecto se orienta inicialmente a operaciones de última milla en **Huancayo, Junín**, considerando zonas cercanas del Valle del Mantaro.

### 3.7 Alcance funcional

El desarrollo debe concentrarse en las funcionalidades definidas en los requisitos del proyecto para evitar que nuevas funcionalidades afecten el tiempo disponible.

### 3.8 Seguridad

La información del sistema debe manejarse de acuerdo con los roles definidos y las credenciales deben mantenerse protegidas fuera del repositorio.

### 3.9 Sostenibilidad

Los indicadores de consumo y emisiones son estimaciones obtenidas a partir de los datos disponibles. Por ello, no deben interpretarse como mediciones ambientales reales.

## 5. Relación con la arquitectura

Las restricciones también influyen en la organización técnica del proyecto.

La **Arquitectura por Capas** permite separar las responsabilidades de la siguiente manera:

```text
Frontend
   ↓
Capa de Presentación
   ↓
Capa de Negocio
   ↓
Capa de Datos
   ↓
Firebase Cloud Firestore
```

Esta separación ayuda a mantener organizado el proyecto y facilita realizar cambios sin afectar innecesariamente las demás partes del sistema.

Por ejemplo:

* Las validaciones de entrada pertenecen a la **Capa de Presentación**.
* Las reglas sobre capacidad, pedidos y rutas pertenecen a la **Capa de Negocio**.
* La comunicación con Firestore pertenece a la **Capa de Datos**.

## 6. Gestión de las restricciones

Las restricciones deben revisarse durante el desarrollo del proyecto.

Cuando una restricción pueda afectar el alcance, tiempo, costo o calidad, se debe evaluar su impacto antes de realizar cambios.

El equipo debe priorizar:

1. Cumplir los requisitos principales del proyecto.
2. Mantener la calidad de los datos.
3. Cumplir el cronograma académico.
4. Mantener controlado el presupuesto.
5. Proteger la información y las credenciales.
6. Mantener organizada la arquitectura del sistema.

---

## 7. Conclusión

EcoRuta Wanka presenta restricciones relacionadas principalmente con el **tiempo académico, presupuesto, tamaño del equipo, disponibilidad de servicios tecnológicos, calidad de los datos, alcance geográfico, seguridad y sostenibilidad**.

Estas restricciones son consideradas durante la planificación y desarrollo del proyecto para mantener un alcance controlado y asegurar que las funcionalidades principales puedan desarrollarse dentro de las condiciones establecidas.

La **Arquitectura por Capas**, junto con la planificación del proyecto y el control de requisitos, permite organizar el desarrollo y responder de manera ordenada ante las restricciones identificadas.
